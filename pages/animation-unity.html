Entropy

"When a world dies, it is by that dying world that another is born."

Entropy - my first personal 3D art project. A visual reflection on death, transformation, loss, and renewal. The piece features a skeleton character situated within a surreal vegetative room, where organic growth intertwines with skeletal remains. Created entirely using Blender's Grease Pencil for 2D elements combined with 3D elements.

This piece represents my journey as both an artist and a person, evolving through the process of becoming and reflecting through creation.

Quiet Neighbours

A first-person investigative game where players explore a mysterious neighborhood, uncovering the hidden stories of its inhabitants. The game features atmospheric lighting, interactive objects, and an AI-driven NPC system that creates dynamic encounters.

Role

Director / 3D Artist / Rigger / Programmer / Animator / Concept Artist

Technical Breakdown

  • Custom NPC AI system using Unity's NavMesh and behavior trees for realistic pathfinding and decision-making
  • Player interaction system with raycasting for object examination and context-sensitive actions
  • Dynamic lighting system that responds to time of day and player actions
  • Procedural animation blending for smooth character transitions
